# Higher-lower-game
Higher Lower Game

A simple command-line game written in Python.

The player is shown two famous people and must guess which one has more followers. Each correct answer increases the score, and the game continues until the player gives a wrong answer.

Features
Randomly selects famous people for comparison
Compares their follower counts
Keeps track of the player's score
Accepts user choices through the command line
Technologies
Python
random module
Python Concepts Practiced
Functions
Dictionaries
Lists
Loops
Conditional statements
Random selection
User input

How to Run

Make sure Python is installed on your computer.

python higherlower.py

Purpose

This project was created to practice Python fundamentals by building a simple interactive guessing game.
